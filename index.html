            Cara kerja parser custom?
            

              
Tulis fungsi parse(ctx) untuk impor dan (opsional) serialize(ctx) untuk ekspor round-trip. JavaScript jalan di Web Worker, Python jalan di pyodide (unduhan pertama ~10MB, butuh internet sekali).

              
parse(ctx) — ctx = { fileName, text, bytes, startLineNum }. Return array [{ name?, message, raw?, index? }; field message wajib, raw = potongan baris asli yang disimpan untuk dipatch saat ekspor, dan index (angka, opsional) = penanda posisi bebas buatan parser — dikembalikan di serialize() sebagai line.index, berguna saat raw bisa duplikat.

              
serialize(ctx) — ctx = { fileName, text, bytes, lines } berisi file asli + baris proyek (name, message, trans_name, trans_message, is_translated, raw, index). Return string (atau bytes untuk format biner). Tanpa serialize(), ekspor jatuh ke JSON generik.

              
Satu proyek terkunci ke satu parser. Parser tersimpan global di browser dan bisa dipakai lintas proyek.

            

          

        

        

          

            

              
              
              
            

            

              
              
              
            

          

          

            

              

                parse(ctx) — Impor 
              

              
            

            

              

                serialize(ctx) — Ekspor (opsional)
